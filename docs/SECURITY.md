# 安全边界与验证

- 数据库名固定为 `sky_takeout_ai`，SQL脚本和初始化命令只操作该库。旧库 `sky_take_out` 不读写、不复用。
- BCrypt 12存密码，JWT_SECRET现在必须由环境变量提供（至少32随机字节的Base64），缺失/无效配置启动失败且不回显值。JWT验签名、issuer、过期、正ID和角色，每次请求检查账号状态。ThreadLocal必须清理；异步工具使用后端ToolContext。退出登录清理客户端Token和状态，但没有服务端单Token黑名单即时撤销。
- 普通用户私有工具没有userId参数；Service按认证用户过滤订单/购物车。管理员统计单独注册，工具及Service再次验ADMIN。
- 请求DTO未知字段返回400，阻止伪造role/userId等字段被悄悄接受。SQL使用固定表名和绑定参数，无生成SQL接口。
- 全部AI工具只读。创建/取消订单、加购、管理商品都通过明确操作的普通API、后端鉴权和业务校验。没有支付工具或真实支付集成。
- 菜单、知识片段、用户输入作为不可信数据；Prompt要求忽略其中指令。安全依赖工具边界，不依赖模型承诺。聊天文本仍可能被注入或产生幻觉，不能宣称彻底防注入；结构化方案单独核价、验ID和预算。
- 每个认证身份AI生成12次/分钟（单实例固定窗口），最多10000个窗口；SSE最多4线程、16队列、45秒超时，回复最大16000字符；Memory限1000会话、每会话20条、空闲30分钟过期。
- 普通业务测试固定Mock；LocalProviderTest将真实适配器连接本机HTTP替身，不访问真实供应商。Provider只尝试一次，每次AI请求最多8次工具调用，45秒后不启动新工具；该截止不等于所有同步请求总时长严格45秒。真实供应商行为和费用治理仍未验证。
- 错误不回显堆栈/参数/供应商异常，并丢弃Provider错误正文；日志记录requestId、conversationId、model、耗时、工具名、次数、成功失败，不记录完整Prompt或工具参数/结果。订单工具去掉地址、联系人、请求键。前端以Vue文本插值渲染AI内容，未启用v-html。
- 普通服务启动不自动创建管理员，仍无开放管理员注册。按本轮用户明确授权，开发演示SQL新增demo_user/demo_admin及BCrypt哈希；开发演示账号见README，不能复用为其他环境的凭据。自选管理员仍可通过 `scripts/Initialize-Admin.ps1` 创建，同名账号失败不覆盖。
- Redis失效的afterCommit异常现在由内部BestEffortCache截获，避免数据库已提交却返回缓存失败；仍可能在TTL内有陈旧菜单，结算只查数据库。不存在数据库与Redis的强一致事务。
- 前端对每次请求保存会话版本，身份变化取消在途请求，旧401不能清除新身份；AI/菜单异步结果同样受会话版本和请求序号约束。图片输入拒绝危险scheme；渲染有站内示意图回退。

## 测试覆盖

无Token、非法/过期/缺角色Token、跨角色接口、伪造DTO身份、两个用户私有数据隔离、异步工具身份清理、只读工具白名单、注入文本仍处在User消息、限流身份隔离、结构化价格/预算拒绝路径。Mock注入测试只证明应用注册边界，不能证明真实模型一定拒绝恶意提示。

## 部署前仍需处理

本项目是本机学习版：未实现短信/微信登录、刷新令牌、密码找回、登录防爆破/账号锁定、跨实例限流、真实支付、生产审计和数据备份策略。HTTP本机开发无TLS，数据库URL开发参数关闭TLS，sessionStorage的Token仍受同源XSS影响。不要直接开放公网；正式部署应启用HTTPS、受信数据库TLS、最小权限数据库账号、上游模型费用配额与监控，并单独评估依赖安全更新。所有测试通过不等于生产安全认证。
